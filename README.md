Word Frequency Search Engine

A simple C++ mini-project that scans a folder, reads all text files, calculates word frequencies, and lets the user search how many times a word appears in each file.

Features

Reads all files in a directory

Counts word occurrences

Stores results in an unordered_map

Search any word and get frequencies sorted by highest count

How to Run
g++ main.cpp -o wordfreq
./wordfreq


Update the folder path inside main() before running.

Usage

Run the program and type any word:

story


Output example:

(file1.txt, 12)
(file2.txt, 5)

Summary

A basic C++ project demonstrating file handling, directory traversal, maps, vectors, and sorting.
